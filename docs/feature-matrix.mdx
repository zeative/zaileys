Find a feature to see whether it works on each provider.

**✓ Yes** — works. **◐ Partial** — works with limits (see the notes). **✗ No** — not available.

Not sure which provider you're on? It's WhatsApp Web unless you created the client with `provider: 'cloud'` — see [Choose a provider](/providers).

## What happens when a feature isn't supported {#what-happens-when-a-feature-isnt-supported}

Zaileys fails straight away with a typed error, so you never wait on a send that silently does nothing:

| Error | Code | Thrown when |
| --- | --- | --- |
| `ZaileysProviderError` | `UNSUPPORTED_ON_CLOUD` | You use a WhatsApp Web–only module or method on the Cloud API, such as `client.group` or `edit()`. |
| `ZaileysBuilderError` | `SEND_FAILED`, with a `ZaileysCloudError` `NOT_IMPLEMENTED` on `error.cause` | You send content the Cloud API can't carry, such as a poll or a carousel. |
| `ZaileysCloudError` | `CONFIG` | You use a Cloud-only call — `webhook()`, `sendTemplate()`, `markRead()`, `client.cloud` — on WhatsApp Web. |

When one codebase serves both providers, check `client.provider` before a provider-specific call:

```ts
import { ZaileysProviderError } from 'zaileys'

try {
  await client.group.create('Weekend trip', ['6281234567890@s.whatsapp.net'])
} catch (error) {
  if (error instanceof ZaileysProviderError) {
    console.warn(`Skipped: ${error.feature} only works on WhatsApp Web`)
  }
}
```
