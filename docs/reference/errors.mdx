This page lists every error Zaileys throws, grouped by class, with the code, the message you'll see, and how to fix it.

<Tip>
  Looking for patterns — catching by code, retrying sends, listening for background errors? Read [Error handling](/data/error-handling).
</Tip>

## Error classes

| Class | Codes | Thrown by |
| --- | --- | --- |
| [`ZaileysBuilderError`](#zaileysbuildererror) | `BuilderErrorCode` | `client.send()`, `msg.reply()`, `ctx.reply()`, edits, deletes, forwards, pins, `loadMedia()` |
| [`ZaileysCloudError`](#zaileysclouderror) | `CloudErrorCode` | The Cloud API client: connecting, `client.cloud`, templates, media downloads |
| [`ZaileysProviderError`](#zaileysprovidererror) | `'UNSUPPORTED_ON_CLOUD'` | WhatsApp Web-only features called with `provider: 'cloud'` |
| [`ZaileysCommandError`](#zaileyscommanderror) | `CommandErrorCode` | `client.command()`, command handlers, middleware |
| [`ZaileysDomainError`](#zaileysdomainerror) | `DomainErrorCode` | `client.group`, `privacy`, `newsletter`, `community`, `profile`, `chat`, `contact`, `business` |
| [`ZaileysAutomationError`](#zaileysautomationerror) | `AutomationErrorCode` | Scheduling, presence, call rejection, rate limiters |
| [`ZaileysStoreError`](#zaileysstoreerror) | `StoreErrorCode` | Auth and message stores |

Every class and every code type is exported from `'zaileys'`.

## What every error has

<ResponseField name="name" type="string">
  The class name, such as `'ZaileysBuilderError'`.
</ResponseField>
<ResponseField name="code" type="string literal union">
  A fixed code from the class's code type. Your editor autocompletes it after an `instanceof` check.
</ResponseField>
<ResponseField name="message" type="string">
  A readable description. The messages below are the exact strings; `<…>` marks a value filled in at runtime.
</ResponseField>
<ResponseField name="cause" type="unknown">
  The lower-level error that triggered this one, when there is one — a driver error, a network failure, WhatsApp's rejection, or another Zaileys error. Check it before reading its fields.
</ResponseField>
<ResponseField name="feature" type="string">
  `ZaileysProviderError` only, which has no `cause`: the name of the Web-only feature you called.
</ResponseField>

```ts
import { ZaileysBuilderError, ZaileysCloudError } from 'zaileys'

try {
  await client.send(jid).poll('Lunch?', ['Nasi goreng', 'Soto'])
} catch (error) {
  if (error instanceof ZaileysBuilderError && error.code === 'SEND_FAILED') {
    const reason = error.cause instanceof ZaileysCloudError ? error.cause.code : error.cause
    console.error('Send failed:', reason)
  } else {
    throw error
  }
}
```

## ZaileysBuilderError

| Code | Thrown when | Message | How to fix it |
| --- | --- | --- | --- |
| `INVALID_OPTIONS` | The client isn't connected — before the connection opens, and always for `broadcast()`, `scheduleAt()` sends, and `forward()` on the Cloud API | `client not connected` | Send from a handler or after the `connect` event. On the Cloud API, wait for `connect()` to finish its health check before sending. |
| `INVALID_OPTIONS` | An option failed validation | `poll() requires a minimum of <n> options`, `location() latitude must be within -90..90, got <value>`, `document() requires a non-empty fileName`, `video() expects a video source, got mime <mime>`, `album() requires a minimum of 2 items`, `buttons() accepts at most <n> buttons`, `duplicate list row id: <id>`, `invalid jid: <value>`, `reply() requires a quoted message or key`, `disappearing() requires a positive integer duration`, … | The message names the method and the rule. |
| `INVALID_OPTIONS` | A status to `status@broadcast` without an audience | `a status sent to status@broadcast needs audience([...]); without it WhatsApp accepts the message but shows it to nobody` | Add `.audience([...])`. |
| `INVALID_OPTIONS` | A message key without a chat address | `message key is missing remoteJid` | Pass a full key, such as `msg.message().key`. |
| `EMPTY_CONTENT` | Nothing to send | `no content set`, `text() requires a non-empty string`, `poll() requires a non-empty question`, `edit() requires a content method before await` | Check the value before sending, and add content before `await`. |
| `INVALID_RECIPIENT` | `audience()` on anything but `status@broadcast`, or group-only content to a non-group | `audience() only applies to status@broadcast, not <jid>`, `<content> can only be sent to a group jid ending in @g.us` | Send to the right kind of address. |
| `USERNAME_NOT_FOUND` | An `@username` recipient doesn't exist | `username "<name>" not found` | Check the spelling, or use a phone JID. |
| `MEDIA_LOAD_FAILED` | A file couldn't be loaded or converted | `fetch <url> failed with status <status>`, `fetch <url> failed: <reason>` (including the 30-second timeout), `read <path> failed: <reason>`, `audio() transcode failed: <reason>`, `sticker() conversion failed: <reason>` | Check the URL and path — paths are relative to the folder you started the bot from. See [Send media](/messaging/media#when-a-send-fails). |
| `SEND_FAILED` | WhatsApp — or the Cloud API — refused the message | `socket sendMessage rejected`, `socket relayMessage rejected`, `album parent send rejected`, `interactive media upload failed` | Read `error.cause` for the real reason. Retrying once often helps on WhatsApp Web. |
| `SEND_FAILED` | The send returned no key | `socket returned no message key`, `album parent returned no message key` | Retry. |
| `MESSAGE_NOT_FOUND` | `forward()` of a message the store doesn't have | `message not found in store for forward` | Use a database-backed [store](/data/storage), and forward soon after the message arrives. |

## ZaileysCloudError

Thrown by the Cloud API client directly. When it happens inside a send, it arrives wrapped — see [Cause chains](#cause-chains).

| Code | Thrown when | Message | How to fix it |
| --- | --- | --- | --- |
| `CONFIG` | A required option is missing | `provider 'cloud' requires cloud.accessToken`, `provider 'cloud' requires cloud.phoneNumberId`, `this operation needs cloud.wabaId (WhatsApp Business Account id)`, `flows.send needs flowId or flowName` | Add the option named in the message. |
| `CONFIG` | A Cloud-only API is used on WhatsApp Web | `webhook() is only available on the cloud provider`, `wa.cloud requires provider: 'cloud'`, `sendTemplate() is only available on the cloud provider`, `markRead(messageId) is only available on the cloud provider` | Use it with `provider: 'cloud'`, after the client has connected. |
| `AUTH` | Meta rejected the token or phone number ID (HTTP 401 or 403) | `cloud auth rejected (<status>) — check accessToken/phoneNumberId`, `graph auth rejected: <Meta's message> (code <code>)` | Generate a fresh access token and check the phone number ID — [Setup](/cloud/setup). |
| `RATE_LIMITED` | Meta answered `429` on all 3 attempts | `graph request failed: <Meta's message> (code <code>)` | Send more slowly — [Limits](/cloud/limits). |
| `REQUEST_FAILED` | A request failed, returned another error status (5xx are retried up to 3 attempts first), or returned no ID | `cloud health-check request failed`, `cloud health-check failed (<status>)`, `graph request failed (network)`, `graph request failed: <Meta's message> (code <code>)`, `graph send returned no message id`, `media download failed (<status>)` | Read the Meta error code in the message; network failures have the original on `cause`. |
| `NOT_IMPLEMENTED` | The content has no Cloud API equivalent yet | `this content type is not supported on the cloud provider yet`, `this interactive layout is not supported on the cloud provider yet`, `interactive media headers are not supported on the cloud provider yet`, `cloud interactive buttons allow at most <n> reply buttons (got <m>)`, `AIRich rich responses (rich: true) are a WhatsApp-Web-only feature …` | Send a supported type — see [Send on the Cloud API](/cloud/messaging) and the [feature matrix](/feature-matrix). |

## ZaileysProviderError

Thrown as soon as you touch a WhatsApp Web-only feature on a client with `provider: 'cloud'`. `code` is always `'UNSUPPORTED_ON_CLOUD'`, and `feature` is one of:

`group`, `privacy`, `newsletter`, `community`, `profile`, `chat`, `contact`, `business`, `presence`, `edit`, `delete`, `rejectCall`, `pin`, `unpin`, `setDisappearing`

Message: `<feature> is not supported by the official WhatsApp Cloud API — it only exists on the web (baileys) provider`

```ts
import { ZaileysProviderError } from 'zaileys'

try {
  await client.group.metadata('120363041234567890@g.us')
} catch (error) {
  if (error instanceof ZaileysProviderError) console.warn(`${error.feature} needs the Unofficial provider`)
}
```

To avoid it, check `client.provider` before calling a Web-only feature.

## ZaileysCommandError

| Code | Thrown when | Message | How to fix it |
| --- | --- | --- | --- |
| `DUPLICATE_COMMAND` | `client.command()` with a name or alias that's taken | `command "<name>" is already registered` | Rename it, or `unregisterCommand()` the old one first. |
| `INVALID_COMMAND_NAME` | An empty spec or alias | `command spec must not be empty`, `empty command segment in spec` | Give every name at least one character; no `\|\|`. |
| `HANDLER_ERROR` | Your command handler threw | `command handler failed` — the original on `cause` | Fix the handler. Delivered through `command-error`. |
| `MIDDLEWARE_ERROR` | A middleware threw, or called `next()` twice | `middleware threw during execution` (original on `cause`), `next() called multiple times` | Call `next()` exactly once. |
| `NO_SENT_MESSAGE` | `ctx.edit()` before any `ctx.reply()` | `ctx.edit requires a prior ctx.reply` | Reply first, then edit. |
| `NOT_CONNECTED` | Declared, not thrown by the current release | — | — |

Details are in the [Commands reference](/reference/commands#errors).

## ZaileysDomainError

| Code | Thrown when | Message | How to fix it |
| --- | --- | --- | --- |
| `NOT_CONNECTED` | A module call before the client connected | `client not connected` | Call it from a handler, or after the `connect` event. |
| `NEWSLETTER_NOT_FOUND` | A channel lookup found nothing | `newsletter <jid> not found` | Check the channel JID. |
| `OPERATION_FAILED` | WhatsApp returned no invite code, an invite couldn't be accepted, or a key had no chat | `invite code unavailable`, `invite acceptance failed`, `message key is missing remoteJid` | Check that the bot is an admin (for invite codes) and that the invite is still valid. |
| `GROUP_NOT_FOUND`, `INVALID_PARTICIPANT` | Declared, not thrown by the current release | — | — |

When WhatsApp itself rejects a module call — for example, adding a member who can't be added — you get Baileys' error, passed through unchanged, not a `ZaileysDomainError`.

## ZaileysAutomationError

| Code | Thrown when | Message | How to fix it |
| --- | --- | --- | --- |
| `NOT_CONNECTED` | Presence or call rejection without a connection | `client not connected`, `cannot reject a call: client not connected` | Call it after the `connect` event. |
| `NOT_CONNECTED` | `client.rejectCall(callId)` without the caller | `rejectCall(callId, from) requires the caller jid` | Pass `from`, or pass the whole `call-incoming` payload. |
| `SCHEDULE_INVALID` | `scheduleAt()` got a bad date or message | `scheduleAt requires a valid Date`, `scheduled builder produced no content`, `scheduled builder evaluation failed` (original on `cause`), `scheduling multi-part messages (e.g. album) is not supported; schedule a single message`, `scheduling interactive/relayed content is not supported; schedule a text or media message` | Pass a `Date` and build one text or media message. |
| `RATE_LIMIT_INVALID` | A rate limit of 0 or less | `perSec must be greater than zero`, `perJidPerSec must be greater than zero`, `burst must be greater than zero` | Use positive numbers. |
| `PRESENCE_FAILED` | A typing, recording, or online update failed | `presence update '<type>' failed` — original on `cause` | Usually temporary; retry. |
| `TASK_FAILED`, `STORE_UNAVAILABLE` | Declared, not thrown by the current release | — | — |

## ZaileysStoreError

These usually surface when the client connects: `await client.connect()` rejects, or — with the default `autoConnect` — the client emits them on the `error` event.

| Code | Thrown when | Message | How to fix it |
| --- | --- | --- | --- |
| `STORE_NOT_AVAILABLE` | The peer package isn't installed | Names the package and an install command, such as `pg is not installed. Run: pnpm add pg` or `redis peer dependency missing. Run: pnpm add redis` | Install the package with your package manager — see [Storage adapters](/reference/storage#at-a-glance). |
| `STORE_CONNECTION_FAILED` | Conflicting or missing constructor options | `pass either client OR url, not both`, `RedisAuthStore requires either client or url`, `PostgresAuthStore: provide either pool or connectionString, not both`, `PostgresAuthStore: pool or connectionString is required` | Pass exactly one of the two. Thrown by the constructor. |
| `STORE_CONNECTION_FAILED` | The database couldn't be opened, reached, or migrated | `failed to open sqlite database at <path>`, `failed to connect to redis at <url>`, `provided redis client is not open (call await client.connect() first)`, `failed to migrate sqlite schema`, `failed to migrate auth schema` | Check the path, URL, credentials, and network. The driver's error is on `cause`. |
| `STORE_READ_FAILED` | A read failed | `redis read failed`, `failed to read creds`, `failed to read <file>`, … | See `cause`. |
| `STORE_WRITE_FAILED` | A write failed | `redis write failed`, `failed to write signal rows`, `failed to write <file>`, … | Check disk space and permissions; see `cause`. |
| `STORE_CORRUPTED` | A SQLite row couldn't be parsed | `failed to parse sqlite blob` | Delete the damaged database and link again. |
| `STORE_CLOSED` | A store was used after the client closed it | `<StoreName> is closed`, such as `SqliteAuthStore is closed` | Create a new `Client` with new store instances. |

## Cause chains

Errors wrap each other, and `cause` keeps the original:

| You catch | `cause` holds |
| --- | --- |
| `ZaileysBuilderError` `SEND_FAILED` from a send on the Cloud API | The `ZaileysCloudError` — `NOT_IMPLEMENTED` for an unsupported type, or `AUTH`, `RATE_LIMITED`, `REQUEST_FAILED` |
| `ZaileysBuilderError` `SEND_FAILED` on WhatsApp Web | Baileys' error |
| `ZaileysBuilderError` `MEDIA_LOAD_FAILED` | The network or file-system error, or the HTTP status as a number |
| `ZaileysCommandError` `HANDLER_ERROR` or `MIDDLEWARE_ERROR` | What your code threw |
| `ZaileysStoreError` | The database driver's error |

Check the wrapped Cloud API code like this:

```ts
import { ZaileysBuilderError, ZaileysCloudError } from 'zaileys'

try {
  await client.send(jid).poll('Lunch today?', ['Nasi goreng', 'Soto ayam'])
} catch (error) {
  if (
    error instanceof ZaileysBuilderError &&
    error.cause instanceof ZaileysCloudError &&
    error.cause.code === 'NOT_IMPLEMENTED'
  ) {
    await client.send(jid).text('Lunch today? Reply 1 for nasi goreng or 2 for soto ayam.')
  }
}
```

## Plain errors

A few failures are plain `Error`s, not Zaileys classes. Match them by `message`:

| Message | Where | How to fix it |
| --- | --- | --- |
| `phoneNumber is required when authType is "pairing"` | `connect()` (or the `error` event) with `authType: 'pairing'` and no `phoneNumber` | Add `phoneNumber`, country code first. |
| `phoneNumber must be E.164 with country code`, `phoneNumber is required` | `validateE164()`. During login they're only logged — as `pairing-code request failed` — and no pairing code arrives. | Use 8–15 digits with the country code, such as `6281234567890`. |
| `qr string is required` | `renderQrInTerminal()` with an empty string | Pass the `qrString` from the `qr` event. |
| `chunk size must be positive` (`RangeError`) | `chunk()` with a size of 0 or less | Use a positive size. |
| `Invalid file type: expected <kind>/*, got <mime>`, `Sticker creation failed: <reason>`, `Invalid media type: expected image or video` | `Media` methods | Check `msg.media.type` before converting — see [Receiving media](/messaging/receiving-media#when-a-download-fails). |
| Baileys' download error, with `media download failed` in the log | `msg.media.buffer()` and `stream()` | Download as soon as the message arrives. |

## Where errors surface

| Situation | What happens |
| --- | --- |
| A call you `await` fails | It rejects with the error — wrap it in `try`/`catch`. |
| The automatic connect from `new Client()` fails | The client emits `error`, if something listens; otherwise it's only logged. |
| A command handler or middleware throws | `command-error`, if something listens; otherwise it's logged. |
| An event handler throws synchronously | Caught and logged; other handlers still run. The logger is silent unless you set `ZAILEYS_DEBUG`. |
| An `async` event handler rejects | Not caught — an unhandled rejection, which stops Node.js by default. |
| A Cloud API webhook handler fails | The webhook still answers Meta with `200`. Nothing reaches the `error` event. |
| Saving a sent message to the store fails | Logged as `recordSent failed`; the send still succeeds. |
